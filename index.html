Ruleset / 01–08 Eight directives

The naming standard.

All constraints resolved
01DIR-01 / IDENTITY

Use a literal company-style name

Name the category directly. The construction should feel as plain and defining as “The Browser Company” or “The Car Rental Company”—never abstract or invented.

+
02DIR-02 / ARTICLE

Start with “The”

The definite article gives the phrase authority and positions MAGEWA as the defining company in its category.

+
03DIR-03 / PURPOSE

Include “for” before the use case

Use “for” as the hinge between identity and purpose: The [core identity] for [use case].

+
04DIR-04 / ACRONYM

Preserve the acronym MAGEWA

Every word maps cleanly and in order: Multi, Agent, Global, Enterprise, Work, Automation.

+
05DIR-05 / FOUNDATION

Use “Multi-Agent” as the technical foundation

State the architecture clearly: coordinated AI agents working together, not generic automation software.

+
06DIR-06 / SCALE

Use “Global Enterprise” to signal scale

Establish MAGEWA as a system for complex, international organizations and operations at scale.

+
07DIR-07 / OUTCOME

Use “Work Automation” as the outcome

Name the result: real business processes, workflows, and enterprise operations moved forward by software.

+
08DIR-08 / LANGUAGE

Keep the full form grammatically readable

The expanded name must work as a natural phrase. The acronym is a constraint, never an excuse for awkward language.
